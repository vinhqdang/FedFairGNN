\caption{\textbf{Empirical Attribute Inference Attack Success Across Release Channels (Bail Recidivism).}
Evaluates sensitive-attribute leakage ($S_k$) through the released fairness statistic $(\mu_0, \mu_1)$ versus the transmitted model parameter updates $g_k = \theta_{\text{global}} - \theta_{\text{local}, k}$.
FTGD successfully neutralizes the fairness-statistic channel ($1.000 \to 0.498$) with no degradation in global AUC ($+0.002$), whereas parameter updates retain residual correlation (AUC $\approx 0.645$).
This demonstrates that FTGD acts as a specialized statistic protection mechanism, complementary to orthogonal parameter-level safeguards (such as Secure Aggregation or parameter DP-SGD).
Probes are evaluated using 5-fold cross-validation grouped strictly by client ID to prevent measuring client re-identification.}
